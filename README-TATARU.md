# 타타루 배구 — 원작 그래픽 스타일 스킨

피카츄배구의 화면과 시스템을 바탕으로 캐릭터와 제목, 스파이크 음성, 코스타 델 솔 배경을 적용한 팬 패러디입니다.

## 실행

```powershell
npm ci
npm start
```

브라우저에서 http://127.0.0.1:8080/ko/ 를 엽니다. 루트 주소도 한국어 페이지로 연결됩니다. 별도 소개 화면이나 시작 버튼 없이 원작의 제작사 오프닝, 타이틀 애니메이션, 모드 선택이 자동으로 이어집니다. 게임 아래에는 조작법 제목 → 원본 한국어 조작법 이미지 `controls_ko.png` → 원본 GitHub 링크 순서로 표시하며, 추가 조작 설명은 생략합니다. 이미지는 화면 너비와 밝은/어두운 테마에 맞춰 표시합니다. 브라우저가 소리 자동 재생을 제한하면 첫 키 입력이나 클릭으로 소리가 활성화됩니다.

## 변경 범위

로컬 개발 서버는 오프라인 캐시와 자동 새로고침을 사용하지 않습니다. 코드를 수정한 뒤에는 브라우저를 직접 새로고침합니다. 예전 개발 캐시 때문에 화면이 반복해서 새로고침되거나 이전 화면이 보이면 `http://127.0.0.1:8080/__reset-game-cache`를 열어 이 게임의 캐시만 정리할 수 있습니다. 설정 저장값은 유지됩니다. 배포 빌드의 오프라인 기능은 그대로입니다.

- 피카츄 → 도트 얀: 네 발 걷기, 점프, 앞으로 돌진, 공중 박치기, 착지, 승패 동작. 각 자세의 머리 크기를 맞추고, 길게 뻗는 자세를 담도록 텍스처 여백을 84×64로 확장했습니다. 슬라이딩은 앞을 또렷하게 바라보고, 스파이크는 힘준 눈매로 머리를 몸통에 붙인 자세입니다. 기본 자세의 표시 크기와 충돌 판정은 유지됩니다.
- 공 → 40×40 도트 타타루 얼굴: 평소 웃음, 실제 스파이크 충돌 때 같은 크기의 아픈 표정. 일반 리시브 또는 새 라운드에서 복귀. 웃는 눈은 원본을 보정하고 실제 도트에서도 동일한 크기와 반짝임을 유지합니다.
- 스파이크 잔상 두 겹 → 파란 타타루 얼굴. 먼 잔상은 더 옅게 표시하고 각각 이전 프레임의 회전각을 사용합니다.
- 공은 이동 방향과 속도에 따라 회전합니다. 수직 이동에서도 회전하며 새 서브는 정면으로 시작합니다. 렌더링만 변경하므로 원작 물리와 AI에는 영향을 주지 않습니다.
- 타이틀 문구 → `타타루 배구`, 그 위의 `포켓몬스터` → `파이널판타지14`. 기존 문구 위치와 등장·확대 연출을 유지하며, 위 문구는 원작의 하늘색과 200×32 텍스처 크기를 그대로 사용하는 도트 글자입니다.
- 타이틀에서 반복되는 피카츄 그림 → 웃는 타타루 얼굴. 공에 사용하는 눈 보정된 도트를 2배로 표시하며, 기존 녹색 바탕·타일 크기·스크롤을 유지합니다.
- 시작 화면의 선택지 이동 소리 → 사용자 제공 `audio [vocals] (3)_[cut_0sec].mp3`를 `tataru-select.mp3`로 적용했습니다. 0.528초 전체 구간을 사용합니다. 위아래로 선택지를 바꿀 때 재생하며, 빠르게 이동해도 겹치지 않고 선택을 확정하면 시작 음성으로 전환됩니다.
- 시작 모드 확정 때 나는 `피카츄~` → 사용자 제공 `audio [vocals] (2)_[cut_2sec].mp3`를 `tataru-start.mp3`로 적용했습니다. 2.04초 전체 구간을 사용하며 페이드아웃은 넣지 않았습니다. Z/Enter로 혼자 또는 둘이 하기 선택을 확정할 때 재생됩니다.
- 경기 배경 → 사용자 스크린샷을 참고한 코스타 델 솔. 청록색 바다, 절벽, 흰 천막, 야자수, 목조 데크와 에테라이트를 432×248 픽셀·32색으로 표시합니다. 상단은 공이 잘 보이는 하늘로 비우고, 원작 구름 네 개를 작게 움직입니다. 코트와 네트의 크기·위치, 충돌 판정은 유지합니다. 실제 에셋과 프롬프트는 `src/resources/assets/images/parody/costa-del-sol-native.png`, `COSTA-PROMPT.md`에 있습니다. 큰 생성 원본은 배포 에셋에서 제외하고 `art/source/costa-del-sol-pixel.png`에 보관했습니다.
- 스파이크의 `삐까~` → 사용자 제공 `audio [vocals] (1)_[cut_1sec] (2).mp3`를 `tataru-spike.mp3`로 적용했습니다. 약 1.08초 전체 구간을 사용하며 페이드아웃은 적용하지 않습니다. 헛스윙이 아닌 실제 스파이크 충돌 때 재생하며, 연속 타격 시 이전 음성을 멈추고 다시 재생합니다. 기존 효과음 켜기/끄기와 스테레오 설정을 따릅니다.
- 타타루 음성 세 개는 파일 기준 통합 음량 -16 LUFS로 통일했습니다. 사용자 제공 원본에서 선택 +8.55dB, 시작 +9.85dB, 스파이크 +6.47dB의 고정 게인만 적용합니다. 인코딩 후 측정값은 각각 -16.05 / -15.99 / -16.00 LUFS이며, 피크에는 최소 약 6dB의 여유가 있습니다. 압축·페이드·잘라내기 없이 길이와 음색을 유지하며, 게임 내 효과음 볼륨 0.35와 BGM·기존 효과음은 그대로입니다.
- 점프·슬라이딩 때 나는 `츄~` 음성은 재생하지 않습니다.
- 경기 종료 때 나는 `삐~삐까츄` 음성도 재생하지 않습니다. 승리·패배 동작과 GAME SET 표시는 유지합니다.

코트, 네트, 점수판, 타격 효과, BGM, 위 음성 변경 외 효과음, 제작사 오프닝, 기본 키, 물리·AI, 점수·서브 로직과 게임·설정 메뉴는 원본을 사용합니다. 구름과 파도 역시 원작 스프라이트를 사용하며 배경만 코스타 델 솔로 바꿨습니다. 한국어 페이지의 소개·홍보 영역과 소개 버튼을 제거하고 자동 실행 및 하단 조작법을 적용했습니다. 이전에 만든 별도 정원 배경·BGM·메뉴·키 배치는 사용하지 않습니다.

## 원작 조작 그대로

| 선수 | 좌 / 우 | 점프 | 아래 | 스파이크 / 돌진 |
|---|---|---|---|---|
| 왼쪽 1P | D / G | R | V (F는 오른쪽+아래) | Z |
| 오른쪽 2P | ← / → | ↑ | ↓ | Enter |

`혼자서 재미있게~`에서 Z로 선택하면 왼쪽 1P, Enter로 선택하면 오른쪽 2P를 조작합니다. `둘이서 같이~`는 원작의 2인 대전입니다. 지상에서 방향키와 공격키를 누르면 돌진하고, 공중에서 공격키를 누르면 박치기합니다. 추가 키 설정이나 모바일 터치 UI를 넣지 않았습니다.

```powershell
npm run build
npx playwright install chromium
npm test
```

빌드 결과는 `dist/`입니다. 테스트는 원작 코드·배경 아틀라스·CSS·사운드 파일 보존, 오프닝 타이밍, Z/Enter 선수 선택, 기본 키, 돌진·박치기, 타타루 표정과 크기, 도트 팔레트, 양쪽 눈, 잔상 모양과 색, 회전·서브 초기화, 득점·서브를 확인합니다. 테스트 화면은 `.local/restored-*.png`에 저장합니다. `?debug=1`에서만 개발 확인용 `window.__tataru`를 제공합니다.
